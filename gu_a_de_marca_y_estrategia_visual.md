# Guía de Identidad y Sistema de Marca: Pipe Herre & Herrefinance

## 1. Visión y Estrategia: El Sistema Modular ("Universo Herre")

Para que **Herrefinance** tenga impacto propio sin desvincularse de tu identidad base (**Pipe Herre**), la solución idónea es estructurar una **arquitectura de marca monolítica flexible**.

Tu elemento distintivo es la **gorra de programador**. Al convertir el isotipo en un **contenedor dinámico**, creas una firma visual inmediata:

* **Marca Matriz (Creador / Developer):**
  * **Símbolo:** Gorra con `{/}`
  * **Significado:** Código, desarrollo, firma personal, versatilidad técnica.
* **Ecosistema de Aplicaciones (Submarcas):**
  * Conservan la silueta y las llaves `{ }`.
  * El glifo interior y el color de acento varían según la función de la app.

```
                  ┌───────────────────────────────┐
                  │          PIPE HERRE           │
                  │      (Gorra con { / })        │
                  │  Identidad Matriz / Creador   │
                  └───────────────┬───────────────┘
                                  │
         ┌────────────────────────┼────────────────────────┐
         ▼                        ▼                        ▼
  HERREFINANCE              HERRETASKS               FUTURAS APPS
  (Gorra con { $ })         (Gorra con { ✓ })        (Gorra con { … })
  Acento: Verde Mint        Acento: Azul Eléctrico   Acento: Específico
```

## 2. Definición Visual de Herrefinance

### 2.1. Isotipo (Icono de la App)
* **Silueta:** Gorra estilizada, geométrica y con trazos limpios que no se degradan en formatos miniatura (32×32 px o 48×48 px).
* **Glifo central:** `{ $ }`. Mantiene la esencia *developer* (las llaves de código) combinada con el símbolo financiero universal, señalando finanzas personales, análisis o inversión inteligente.
* **Proporciones:** Corona amplia para dar protagonismo legible al contenido interior.

### 2.2. Logotipo y Jerarquía Tipográfica
Para equilibrar solidez técnica y accesibilidad:
* **HERRE:** Tipografía Sans-Serif geométrica en peso **Black / Extra Bold**, mayúsculas, espaciado ligeramente compacto.
* **FINANCE:** Misma familia tipográfica en peso **Light / Regular**, o en caja baja (`finance`), diferenciado mediante color de acento o contraste de peso.

```
   [ ISOTIPO ]   HERRE FINANCE
                 └──▲──┘ └──▲──┘
                    │       └── Fino / Acento (Especialidad)
                    └────────── Grueso / Blanco (Firma de marca)
```

## 4. Reglas de Escala y Uso

1. **Favicon / App Icon:**
   * Utilizar la versión contenida en squircle (borde redondeado).
   * Eliminar texto; usar únicamente el isotipo de la gorra con `{ $ }`.
2. **Navbar / Encabezado Web:**
   * Versión horizontal: Isotipo a la izquierda + texto `HERREFINANCE` a la derecha.
3. **Firmas y Splash Screens:**
   * En la pantalla de carga se recomienda incluir al pie:  
     *“A product by Pipe Herre”* o el icono `{/}` en tamaño reducido.
